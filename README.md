# ASCEND — Política de Privacidade

Site estático com a Política de Privacidade do app **ASCEND** (Android, `com.flashmango.ascend`),
publicado na Vercel para uso como URL de privacidade na Google Play.

- `index.html` — a política (pt-BR). Sem build, sem dependências.
- Para atualizar: edite `index.html`, ajuste a data em "Última atualização" e faça push na `main`.
